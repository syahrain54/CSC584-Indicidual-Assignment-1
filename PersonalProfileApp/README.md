
# Personal Profile Web Application

## Project Description

This project is developed for CSC584 Individual Assignment 1.
It is a simple Personal Profile Web Application that allows
users to enter their personal information through an HTML form.

The submitted information is processed using a Java Servlet
and displayed on a JSP page.

## Technologies Used

- HTML
- CSS
- Java Servlet
- JavaServer Pages (JSP)
- NetBeans IDE 8.2
- GlassFish Server

## Features

- Personal information input form
- HTTP POST form submission
- Servlet-based data processing
- JSP profile display
- Responsive CSS design

## How to Run

1. Open the project in NetBeans IDE.
2. Configure GlassFish Server.
3. Right-click the project and select Run.
4. Open the application in a web browser.
5. Fill in the personal profile form.
6. Click Submit Profile to view the submitted information.
